## 🎯 What craft-apps-manager Does

craft-apps-manager covers four main jobs, all from one desktop window.

**Installing Craft apps.** The app helps you install Storytold Craft apps without hunting for the right file or folder. It keeps installs consistent so your setup stays predictable, and it removes the guesswork of where files should go.

**Updating Craft apps.** Instead of checking for updates one app at a time, you can let craft-apps-manager handle the update flow. It looks for newer versions and helps you move from one release to the next without rebuilding your setup from scratch.

**Managing backups.** Backups are the safety net for creative work and app settings. craft-apps-manager lets you create and manage backup copies in a structured way, so you have something to return to when an update does not go as planned or a setting gets changed by accident.

**Building from source.** Some users want to build a Craft app from its source code rather than use a ready-made release. craft-apps-manager includes a source-building path for that situation, so you do not need a separate set of tools for it.

## 💾 Backups and Safety

Updates can change how an app behaves. A backup gives you a copy to fall back on. craft-apps-manager is designed around that idea, so backup management is part of the normal workflow rather than an afterthought.

A practical rhythm for most users:

- Create a backup before you update a Craft app you rely on daily.
- Keep more than one backup if you experiment often with new releases.
- Name or note your backups so you can tell them apart later.
- Check that a backup exists before you change anything important.

You stay in control of what gets backed up and when. The app organizes the process; the decisions remain yours.
